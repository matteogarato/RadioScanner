<a name="english"></a>
# 🇬🇧 English

A single Bash script for Ubuntu/Debian that listens to aviation (AM airband) frequencies with an RTL-SDR USB dongle, records **one WAV file per radio transmission**, and transcribes each one locally with [faster-whisper](https://github.com/SYSTRAN/faster-whisper). Everything runs offline after the first Whisper model download.

## Features

- Scans several airband frequencies at once using `rtl_fm`.
- Detects individual transmissions (software voice gate + silence gap) and saves each as its own WAV.
- Transcribes in a background thread, so recording never stops while Whisper is working.
- Writes a `.txt` transcription next to every WAV, plus a running log.
- Optionally deletes recordings in which Whisper finds no speech (pure noise).
- Automatic setup: installs system packages, creates a Python virtual environment, installs dependencies, downloads the Whisper model, blacklists the DVB-T kernel driver and tests the dongle.
- Graceful shutdown: CTRL+C stops the radio and waits for pending transcriptions (a second CTRL+C forces exit).

## Requirements

| Item | Details |
|---|---|
| OS | Ubuntu / Debian (uses `apt-get`) |
| Hardware | RTL-SDR USB dongle and an antenna suited to the airband (about 118–137 MHz) |
| Privileges | `sudo` (only for the setup step) |
| Python | 3.9 or newer |
| Internet | Needed on the first run only (packages and Whisper model download) |
| Disk | At least 2 GB free recommended (about 2 MB per minute of recorded speech) |

The setup step installs these automatically if missing: `python3`, `python3-venv`, `rtl-sdr`, `usbutils`, and, inside the virtual environment, `faster-whisper`, `numpy` and `av<19`.

## Quick start

```bash
chmod +x sdr_airband_transcriber.sh
./sdr_airband_transcriber.sh
```

The first run checks and installs everything, then starts recording. Press **CTRL+C** to stop.

If setup adds you to the `plugdev` group or blacklists the DVB-T driver, you may be asked to unplug/replug the dongle, log out and back in, or reboot. Then run the script again.

## Usage

```text
./sdr_airband_transcriber.sh               check/install requirements, then record
./sdr_airband_transcriber.sh --setup-only  only check/install requirements
./sdr_airband_transcriber.sh --skip-setup  record without the setup checks
```

## Output

Everything is created next to the script:

```text
sdr_registrazioni_aeree/
├── atc_20261109_101530_123456.wav   one transmission
├── atc_20261109_101530_123456.txt   its transcription
└── trascrizioni.log                 full activity log
whisper-env/                         Python virtual environment
sdr_transcriber.py                   worker, regenerated at every run
```

> `sdr_transcriber.py` is generated by the Bash script each time it runs. Do not edit it: change the configuration block in the `.sh` file instead.

## Configuration

All settings are at the top of the script.

### Whisper

| Variable | Default | Description |
|---|---|---|
| `WHISPER_MODEL` | `base` | `tiny`, `base`, `small` or `medium`. Larger = more accurate but slower and more RAM. |
| `WHISPER_LANG` | `en` | `en`, `it`, or `""` for automatic detection. |
| `CPU_THREADS` | `2` | Whisper CPU threads. Fewer = lower load, slower transcription. `0` = library default. |

### SDR

| Variable | Default | Description |
|---|---|---|
| `SAMPLE_RATE` | `16000` | Audio sample rate in Hz. |
| `GAIN` | `42` | Tuner gain passed to `rtl_fm`. |
| `DC_BLOCK` | `1` | Enables the `rtl_fm` DC blocking filter (recommended for AM). |
| `FREQUENCIES` | see script | List of frequencies **in Hz**, e.g. `120200000` = 120.200 MHz. Edit it for your area. |

### Squelch and transmission detection

| Variable | Default | Description |
|---|---|---|
| `SQUELCH` | `35` | `rtl_fm` hardware squelch. Must be `> 0` when scanning several frequencies. Higher = ignores weaker signals. |
| `VOICE_RMS` | `50` | Software voice gate. Raise it if noise is recorded, lower it if quiet speech is missed. |
| `GAP_SECONDS` | `1.5` | Silence duration that marks the end of a transmission. |
| `MIN_SECONDS` | `1.0` | Recordings shorter than this are discarded. |
| `MAX_SECONDS` | `120` | Safety cap for a single recording. |
| `DELETE_NO_SPEECH` | `1` | Delete the WAV (and create no `.txt`) when Whisper finds no speech. |

## How it works

1. `rtl_fm` demodulates AM audio from the configured frequencies and hops between them while the squelch is closed.
2. The Python worker reads the raw 16-bit audio stream and computes the RMS of each chunk (DC offset removed).
3. When the level exceeds `VOICE_RMS`, recording starts; it ends after `GAP_SECONDS` without voice or at `MAX_SECONDS`.
4. The WAV is saved and queued; a background thread transcribes it with faster-whisper (CPU, `int8`, VAD filter on, with an air-traffic-control prompt to help vocabulary).
5. The transcription is written to a `.txt` and to the log.

## Troubleshooting

- **"No RTL-SDR dongle detected"**: plug it in, try another USB port.
- **USB permission error**: the script adds your user to `plugdev`; unplug/replug the dongle and log out/in (or reboot).
- **"Dongle is busy"**: close other SDR programs; after the DVB-T driver was just blacklisted, reboot.
- **Every transcription fails with `unexpected keyword argument 'metadata_errors'`**: PyAV 19 is incompatible with faster-whisper 1.2.x. The setup pins `av<19` automatically; re-run without `--skip-setup`.
- **Too many noise recordings**: raise `VOICE_RMS` and/or `SQUELCH`.
- **Missed quiet transmissions**: lower `VOICE_RMS` / `SQUELCH`, or adjust `GAIN`.
- **High CPU/RAM usage**: use `WHISPER_MODEL="tiny"` or `"base"` and lower `CPU_THREADS`.
- **`--skip-setup` fails with "Python environment not found"**: run the script once without that flag.

## Notes

- Transcriptions are automatic and may contain errors, especially with accents, noise and aviation jargon. **Never use them for operational or flight-safety purposes.**
- This is a receive-only tool. Rules on receiving, recording and storing radio communications vary by country: check your local regulations.

# 🇮🇹 Italiano

Uno script Bash per Ubuntu/Debian che ascolta le frequenze aeronautiche (AM, banda aeronautica) con una chiavetta USB RTL-SDR, registra **un file WAV per ogni trasmissione radio** e trascrive ciascuna in locale con [faster-whisper](https://github.com/SYSTRAN/faster-whisper). Dopo il primo download del modello Whisper funziona interamente offline.

## Funzionalità

- Scansione di più frequenze aeronautiche contemporaneamente con `rtl_fm`.
- Rilevamento delle singole trasmissioni (soglia vocale software + pausa di silenzio) e salvataggio di ognuna in un WAV separato.
- Trascrizione in un thread in background: la registrazione non si ferma mentre Whisper lavora.
- Un file `.txt` con la trascrizione accanto a ogni WAV, più un log continuo.
- Eliminazione opzionale delle registrazioni in cui Whisper non trova parlato (solo rumore).
- Setup automatico: installa i pacchetti di sistema, crea l'ambiente virtuale Python, installa le dipendenze, scarica il modello Whisper, mette in blacklist il driver DVB-T del kernel e testa la chiavetta.
- Arresto ordinato: CTRL+C ferma la radio e attende le trascrizioni in sospeso (un secondo CTRL+C forza l'uscita).

## Requisiti

| Elemento | Dettagli |

| Hardware | Chiavetta USB RTL-SDR e un'antenna adatta alla banda aeronautica (circa 118–137 MHz) |

Il setup installa automaticamente, se mancanti: `python3`, `python3-venv`, `rtl-sdr`, `usbutils` e, nell'ambiente virtuale, `faster-whisper`, `numpy` e `av<19`.

## Configurazione

Tutte le impostazioni si trovano all'inizio dello script.

### Whisper

| Variabile | Default | Descrizione |
|---|---|---|
| `WHISPER_MODEL` | `base` | `tiny`, `base`, `small` o `medium`. Più grande = più accurato ma più lento e con più RAM. |
| `WHISPER_LANG` | `en` | `en`, `it`, oppure `""` per il rilevamento automatico. |
| `CPU_THREADS` | `2` | Thread CPU di Whisper. Meno thread = meno carico, trascrizione più lenta. `0` = valore predefinito della libreria. |

### SDR

| Variabile | Default | Descrizione |
|---|---|---|
| `SAMPLE_RATE` | `16000` | Frequenza di campionamento audio in Hz. |
| `GAIN` | `42` | Guadagno del tuner passato a `rtl_fm`. |
| `DC_BLOCK` | `1` | Attiva il filtro di blocco DC di `rtl_fm` (consigliato per AM). |
| `FREQUENCIES` | vedi script | Elenco di frequenze **in Hz**, es. `120200000` = 120,200 MHz. Modificalo in base alla tua zona. |

### Squelch e rilevamento delle trasmissioni

| Variabile | Default | Descrizione |
|---|---|---|
| `SQUELCH` | `35` | Squelch hardware di `rtl_fm`. Deve essere `> 0` con più frequenze. Più alto = ignora i segnali più deboli. |
| `VOICE_RMS` | `50` | Soglia vocale software. Aumentala se viene registrato rumore, abbassala se si perde parlato debole. |
| `GAP_SECONDS` | `1.5` | Durata del silenzio che segna la fine di una trasmissione. |
| `MIN_SECONDS` | `1.0` | Le registrazioni più brevi vengono scartate. |
| `MAX_SECONDS` | `120` | Limite di sicurezza per una singola registrazione. |
| `DELETE_NO_SPEECH` | `1` | Elimina il WAV (senza creare il `.txt`) se Whisper non trova parlato. |

## Come funziona

1. `rtl_fm` demodula l'audio AM dalle frequenze configurate e passa da una all'altra mentre lo squelch è chiuso.
2. Il worker Python legge il flusso audio grezzo a 16 bit e calcola l'RMS di ogni blocco (senza offset DC).
3. Quando il livello supera `VOICE_RMS` inizia la registrazione; termina dopo `GAP_SECONDS` senza voce o a `MAX_SECONDS`.
4. Il WAV viene salvato e messo in coda; un thread in background lo trascrive con faster-whisper (CPU, `int8`, filtro VAD attivo, con un prompt sul traffico aereo per aiutare il vocabolario).
5. La trascrizione viene scritta in un `.txt` e nel log.

## Risoluzione dei problemi

- **"No RTL-SDR dongle detected"**: collega la chiavetta, prova un'altra porta USB.
- **Errore di permessi USB**: lo script ti aggiunge a `plugdev`; scollega/ricollega la chiavetta e fai logout/login (o riavvia).
- **"Dongle is busy"**: chiudi altri programmi SDR; se il driver DVB-T è stato appena messo in blacklist, riavvia.
- **Ogni trascrizione fallisce con `unexpected keyword argument 'metadata_errors'`**: PyAV 19 non è compatibile con faster-whisper 1.2.x. Il setup blocca automaticamente `av<19`; riesegui senza `--skip-setup`.
- **Troppe registrazioni di solo rumore**: aumenta `VOICE_RMS` e/o `SQUELCH`.
- **Trasmissioni deboli perse**: abbassa `VOICE_RMS` / `SQUELCH`, oppure regola `GAIN`.
- **Uso elevato di CPU/RAM**: usa `WHISPER_MODEL="tiny"` o `"base"` e riduci `CPU_THREADS`.
- **`--skip-setup` fallisce con "Python environment not found"**: esegui lo script una volta senza quell'opzione.

## Note

- Le trascrizioni sono automatiche e possono contenere errori, soprattutto con accenti, rumore e gergo aeronautico. **Non usarle mai a fini operativi o di sicurezza del volo.**
- Lo strumento è solo ricevente. Le norme su ricezione, registrazione e conservazione delle comunicazioni radio variano da paese a paese: verifica la normativa locale.
